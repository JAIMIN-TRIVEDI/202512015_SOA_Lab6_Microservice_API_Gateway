1. Lab Objective & Scope 
Continue the application developed in Lab 7 and move it toward a practical DevOps workflow: Kubernetes for 
orchestration, basic GitHub Actions for CI, and Prometheus/Grafana for monitoring. 
By the end of the task, you should demonstrate: 
• Deployment of the API Gateway, User Service, Product Service and Order Service on Kubernetes. 
• Use of Pods, Deployments, Services, namespaces and configuration. 
• Kubernetes service discovery, scaling and self-healing. 
• A basic GitHub Actions workflow for checkout, dependency installation, testing and Docker image creation. 
• Prometheus metric collection/querying and Grafana visualization. 
• API traffic generation followed by observation of monitoring changes.

4. Part B — Basic GitHub Actions CI 
4.1 Create the CI Workflow 
Create a workflow under .github/workflows/ that runs when code changes. 
.github/workflows/ci.yml 
• Trigger on push and/or pull_request. 
• Use an Ubuntu runner. 
• Checkout the repository. 
• Install dependencies using the project's actual technology. 
• Run tests. 
• Build the Docker image. 
Basic structure: 
name: CI 
on: [push, pull_request] 
jobs: 
  build-test: 
    runs-on: ubuntu-latest 
    steps: 
      - uses: actions/checkout@v4 
      - run: npm ci 
      - run: npm test 
      - run: docker build -t app:${{ github.sha }} . 
Adaptation: Replace npm commands with commands used by the actual project. If the repository contains 
multiple services, ensure the required services are checked and their Docker images can be built. 
4.2 Verify GitHub Actions
